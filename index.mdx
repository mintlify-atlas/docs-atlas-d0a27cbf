Forti4D is a Python toolkit for static analysis of Fortran source code. It runs a 19-step pipeline against hybrid F77/F90/F95 corpora — the kind of real-world legacy code where general-purpose parsers typically fail — and produces structured CSV reports, Graphviz call graphs, and a self-contained HTML report with filterable, sortable results.

## What forti4d analyzes

Forti4D treats a Fortran codebase as a four-dimensional object (the **MI4D model**) and extracts metrics across four axes: physical file topology, logical program structure, symbol scope, and control-flow state. The full 19-step pipeline covers:

<CardGroup cols={3}>
  <Card title="Unit Inventory" icon="list" href="/analyzers/inventory">
    Every PROGRAM, MODULE, SUBROUTINE, and FUNCTION with its type, parent, and line range.
  </Card>
  <Card title="Call Graph" icon="diagram-project" href="/analyzers/dependencies">
    CALL, USE, and function-call edges resolved to a Fan-In / Fan-Out impact matrix.
  </Card>
  <Card title="Complexity" icon="chart-line" href="/analyzers/complexity-sloc-clones">
    McCabe cyclomatic complexity, precise SLOC counts, and clone detection per unit.
  </Card>
  <Card title="Dead Code" icon="skull" href="/analyzers/reachability">
    BFS reachability from all entry points flags units that are never called.
  </Card>
  <Card title="Scope Analysis" icon="layer-group" href="/analyzers/scope-manager">
    Variable declarations, derived types, IMPLICIT rules, and EQUIVALENCE aliasing.
  </Card>
  <Card title="Migration Risk" icon="triangle-exclamation" href="/analyzers/reporting">
    Composite risk scores rank every unit for F77→F90/modern migration effort.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Install forti4d">
    ```bash
    pip install forti4d
    ```
  </Step>
  <Step title="Run the full pipeline against your project">
    ```bash
    forti4d --project /path/to/fortran/source --output results/
    ```
  </Step>
  <Step title="Open the HTML report">
    Open `results/report.html` in a browser. Use the built-in filters to sort units by risk score, complexity, or reachability status.
  </Step>
</Steps>

## Key capabilities

| Capability | Output file |
|---|---|
| Unit inventory | `inventory_report.csv` |
| Call graph & Fan-In/Fan-Out | `dep_02_unit_graph.csv`, `dep_03_impact_matrix.csv` |
| Statement density profile | `report_density.csv` |
| McCabe cyclomatic complexity | `report_complexity.csv` |
| Dead code detection | `report_reachability.csv` |
| Clone detection | `report_clones.csv` |
| COMMON block coupling | `common_coupling.csv` |
| Symbol declarations | `symbol_variables.csv`, `symbol_signatures.csv` |
| Migration risk ranking | `report_prioritization.csv` |
| Interactive HTML report | `report.html` |

<Note>
Forti4D supports FORTRAN 77, Fortran 90, and Fortran 95. Fortran 2003+ OOP features (`CLASS`, `TYPE EXTENDS`, procedure pointers) are not currently analyzed. See [Known Limitations](/outputs/limitations) for details.
</Note>
